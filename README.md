# Capstone Project – Frontend

## Overview
This is the frontend of my full-stack Capstone Project built using Vue 3. The application provides a responsive interface for managing products with full CRUD functionality and dynamic routing. It integrates with a Node.js and MySQL backend via REST APIs.

## Tech Stack
- Vue 3
- Composition API (setup, ref, reactive)
- Vue Router
- Vuex (state management)
- Axios (API integration)
- Bootstrap / CSS
- Node.js + MySQL (Backend)

## Key Features
- Dynamic routing using Vue Router
- Centralized state management with Vuex
- CRUD operations (Create, Read, Update, Delete)
- API integration with backend services
- Responsive and user-friendly interface
- Component-based architecture

## Project Setup

Install dependencies:
npm install

Run development server:
npm run serve

Build for production:
npm run build
